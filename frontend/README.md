# Frontend Setup

## Installation

1. Install Node.js (if not installed): https://nodejs.org/

2. Install dependencies:

```bash
npm install
```

3. Run development server:

```bash
npm start
```

Application will open at http://localhost:3000

## Build for Production

```bash
npm run build
```

## Important

Make sure the backend server is running on http://localhost:5000 before using the app!
